# LS-Face Study Dashboard

Read-only Next.js dashboard (App Router, static export) for the LS-Face study. Deploys
to Vercel. See [`docs/ui/DESIGN.md`](../../docs/ui/DESIGN.md) §6.

## Local

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export -> ./out
```

## Data

Everything the dashboard renders is generated by
[`scripts/build_study_manifest.py`](../../scripts/build_study_manifest.py) from
[`docs/ui/study_status.yml`](../../docs/ui/study_status.yml) and a scan of `reports/`:

- `data/manifest.json`: study status, legs, paper coverage, benchmark summaries, figures
- `content/docs/**`: copied markdown (slugified; the `docs/READ THIS/` space is
  normalized to `read-this/`)
- `content/results/**`: copied per-leg `summary.json`
- `public/figures/**`: copied figures

These are **committed on purpose** (not gitignored) so Vercel's shallow clone has them.
Re-run the manifest script and commit whenever the source data changes.

## Deploy to Vercel

1. Import this repo in Vercel.
2. **Root Directory** = `ui/dashboard`. Framework preset auto-detects as Next.js.
3. Deploy. Auto-redeploys on push via the standard GitHub integration.

The app is fully self-contained inside `ui/dashboard/`. It never reads files outside
its Root Directory (`next.config.mjs` uses `output: "export"`, no server runtime), so
Vercel's Root-Directory sandbox (`..` reads forbidden) is a non-issue by construction.

## Design system

- Calm, neutral academic palette; legibility over novelty.
- Full light/dark support (system default + a manual toggle, no flash on load).
- Accessible: skip link, visible focus rings, reduced-motion honoured, semantic tables.
- Responsive: wide tables scroll inside their own container; the page body never does.
