# Purpose
This subfolder holds non-official/canonical tests, scripts, outputs, and reports that uses experimental configs.

Results published here may not necessarily reflect what the research stand for.

This folder is intended to hold new data while it is being tested, cross-checked, and verified to be up-to-spec with the research requirements.

# Promotion
Results, reports, and scripts must be approved to be promoted to official and moved to the root ./docs/
