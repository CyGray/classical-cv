# Independence-test threshold master table

**Purpose:** the one place that lists every LBPH/SFace `tau_accept` /
`l2_genuine` value in play across this workspace, which family it belongs to
(standalone single-engine / joint hybrid-derived / actually-deployed), where
its artifact lives, and whether it's closed (has an in-repo, reproducible
derivation) or open (doesn't yet, or disagrees with something else).

**Rule for anyone adding a row later:** never quote a threshold from prose —
not this file either. Every row must cite either a runtime file
(`classical-cv/src/hybrid/thresholds.json`, `classical-cv/src/sface/recognizer.py`)
read at the time this table was last updated, or a specific artifact path
under `docs/results/independence_test/independence/`. A row with no artifact path and
no runtime-file citation is by definition **open**.

*Last updated: 2026-08-02 (LBPH `tau_accept` unification decision — rows 1, 3, 4;
SFace `l2_genuine` band≈marginal resolution — row 5; `tau_reject` canonization —
row 6, new).*

## What's closed vs open, and why it matters for the robustness test

- **Rows 1, 2, 4, 5, and 6 are closed.** Rows 1 and 2 both have a reproducible, spot-checked, in-repo derivation on the same probes, same detector, same dataset build (`classical-cv/data/lfw-dataset`, original-unfunneled, SHA-verified per `classical-cv/docs/audits/STATE-08-01.md`). Row 4 closed 2026-08-02 by adopting row 1's value into the deployed config, resolving NOTES.md item 2. Row 5 closed 2026-08-02 as immaterial (band ≈ marginal on LFW, no config change), resolving NOTES.md item 4. Row 6 closed 2026-08-02 by canonizing `tau_reject = 140.13` (advisor sign-off), resolving NOTES.md item 3. `cv_only` / `dl_only` / `cascade` (all three gate parameters) can all be scored against the current `thresholds.json` without further open questions.
- **Row 3 is closed as a measurement but resolved as a decision (rejected)** — the number is real and reproducible, but it measures a harness bug (box-crop vs full-frame), not a legitimate alternate calibration. Do not adopt it.
