# Independence-test threshold master table

**Purpose:** the one place that lists every LBPH/SFace `tau_accept` /
`l2_genuine` value in play across this workspace, which family it belongs to
(standalone single-engine / joint hybrid-derived / actually-deployed), where
its artifact lives, and whether it's closed (has an in-repo, reproducible
derivation) or open (doesn't yet, or disagrees with something else).

**Rule for anyone adding a row later:** never quote a threshold from prose —
not this file either. Every row must cite either a runtime file
(`classical-cv/src/hybrid/thresholds.json`, `classical-cv/src/sface/recognizer.py`)
read at the time this table was last updated, or a specific artifact path
under `classical-cv/reports/independence/`. A row with no artifact path and
no runtime-file citation is by definition **open**.

*Last updated: 2026-08-02 (LBPH `tau_accept` unification decision — rows 1, 3, 4).*

## What's closed vs open, and why it matters for the robustness test

- **Rows 1, 2, and 4 are closed** — rows 1 and 2 both have a reproducible, spot-checked, in-repo derivation on the same probes, same detector, same dataset build (`classical-cv/data/lfw-dataset`, original-unfunneled, SHA-verified per `classical-cv/docs/audits/STATE-08-01.md`). Row 4 closed 2026-08-02 by adopting row 1's value into the deployed config, resolving NOTES.md item 2. `cv_only` / `dl_only` / `cascade`-outright-accept can all be scored against 67.03325520645528 without further work.
- **Row 3 is closed as a measurement but resolved as a decision (rejected)** — the number is real and reproducible, but it measures a harness bug (box-crop vs full-frame), not a legitimate alternate calibration. Do not adopt it.
- **Row 5 is open** — *why* the deployed SFace value (1.0313) is the one in the live config, versus the standalone-derived 1.0306278467178345, cannot currently be reconstructed from provenance strings, dated audit notes, or git history alone. This blocks NOTES.md item 4 ("optimal hybrid SFace threshold").
- **`tau_reject` (not tracked by this file — see Cross-reference below) is still open**, and separately: the deployed value (88.4927) is now **suspect** for the same reason row 3 was rejected — it comes from the identical full-frame `independence_test.py` run. NOTES.md item 3.
