### B2. Per-run threshold stability (backfilled without re-running)
- `src/independence_common.py`: new `per_run_error_pair_thresholds(runs, k)`
  — computes the k-th-smallest distance independently per seeded run and
  reports mean/std/min/max, instead of `aggregate_pairwise_results`'s
  mean-before-rank point estimate.
- `src/lbph/independence_test.py`, `src/eigenfaces/independence_test.py`,
  `src/fisherfaces/independence_test.py`: each now stores
  `normalized_distance` per pair inside `all_runs_records` (previously
  raw-only), writes `random_seed_base` into `summary.json`, and adds a
  `per_run_thresholds` block using the same `k` as the published spec.
- New script `scripts/per_run_thresholds.py`: backfills the stability numbers
  from the **already-committed** `_raw_runs/run_*/comparisons.csv` — no
  re-running the N×(N-1) sweep. Documents an honest limitation: those
  committed CSVs only store `distance_normalized`, not `raw_distance`, so the
  backfill can only recover the normalized-scale spread (new runs going
  forward record both scales).
- **Finding surfaced, not hidden** (per the spec's own instruction): the
  per-run normalized thresholds are materially *lower* than the committed
  mean-before-rank normalized thresholds for all three families:

  | Family | Per-run mean ± std (range) | Committed (mean-before-rank) |
  |---|---|---|
  | LBPH | 68.03 ± 1.83 (64.94–71.49) | 85.88 |
  | Eigenfaces | 48.20 ± 2.51 (43.68–51.97) | 71.00 |
  | Fisherfaces | 43.15 ± 4.17 (36.49–50.78) | 66.38 |

  Cause: `aggregate_pairwise_results` averages each pair's *raw* distance
  across runs, then renormalizes against the *pooled* max distance, which is
  typically smaller/less noisy than any single run's own per-run max — so
  dividing by it inflates the normalized threshold relative to what any one
  run's own normalization would show. The raw-distance/realized-FAR operating
  points are unaffected (never pass through per-run normalization); only the
  displayed normalized percentage is inflated. Documented in both
  `reports/figures/METRICS.md` (Table 3 footnotes) and `docs/PAPER.md` §4.1.

### B3. EER computation
- Discovered mid-implementation that an EER function (`equal_error_rate` in
  `src/benchmark/tar_at_far.py`) **already existed** since the initial commit
  and was already wired into `scripts/sweep_classical_configs.py`'s table —
  the spec's audit claim ("no EER anywhere") was an audit miss, not
  something I needed to build from scratch for that path.
- What was genuinely missing: the per-model evaluation JSON path
  (`src/classical_faces/pipeline.py:compute_threshold_sweep`, used by
  `evaluate.py`) had no EER. Added `equal_error_rate(sweep)` next to
  `compute_threshold_sweep` — walks the (threshold, FAR, FRR) sweep for the
  sign change of FAR−FRR and linearly interpolates the crossing; returns
  `None` if either rate is undefined (closed-set, no impostors) or the curves
  never cross inside the swept range (no extrapolation). Wired into the
  evaluation JSON as `report["eer"]`, with a comment noting the ~1.79-pp
  granularity on La Salle's 56 genuine probes.
- Verified with synthetic sweeps: interpolates a real crossing correctly,
  returns `None` for a non-crossing sweep and for a closed-set (no-impostor)
  sweep.
- Did not implement the *optional* "mark the EER point on the ROC figure"
  suggestion from A5 — left for a future pass.

- `main.py:performance_args_for_independence_full`: **removed** the

- `src/independence_report.py:run_streaming_and_save`: docstring now states
